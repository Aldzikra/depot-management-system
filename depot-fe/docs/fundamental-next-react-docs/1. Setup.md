# 📝 Catatan Progres: Tahap 1 (Setup, Konsep & Komponen Dasar)

## Apa Aja yang Udah Dipraktekkan & Dipahami:
1. **Setup Next.js & App Router**: Berhasil nempatin proyek Next.js + Tailwind CSS dan paham struktur filenya.
2. **Paham Konsep shadcn/ui**: Paham bedanya shadcn sama library biasa (kodenya masuk ke folder proyek sendiri, bukan di `node_modules`).
3. **Inisialisasi CLI**: Berhasil ngerun `npx shadcn@latest init` sampe selesai.
	   - **Primitive UI**: Radix UI
	   - **Preset Tampilan**: Nova
4. **Install Komponen Utama**: Berhasil meng-add komponen `button`, `input`, `card`, dan `calendar` via CLI shadcn.
5. **Mekanisme Auto-Generate & Design Tokens**: Paham cara kerja CLI saat bikin file `.tsx` dan fungsi CSS Variables di `globals.css`.
6. **Next.js App Router Fundamentals**:
	   - Paham routing berbasis file `page.tsx` (beda dengan `App.tsx` di React biasa).
	   - Paham fleksibilitas penulisan `export default` dan penamaan fungsi.
	   - Paham keunggulan penggunaan tag semantik `<main>` dibanding `<div>`.
	   - Mengetahui cara kerja *File-based Metadata* saat ganti `icon.png` (favicon) di folder `app/`.
7. **Troubleshooting Editor & JSX**:
	   - Paham penyebab warning `@apply` Tailwind v4 di VS Code dan cara mengatasinya via extension/settings.
	   - Paham penggunaan sintaks *Self-Closing Tag* (`/>`) di JSX.
8.  Component = PascalCase, Props, Variable = camelCase
